# Agent Skills Catalog (`_agents/skills/`)

This directory contains specialized skill packages that equip AI agents with tools, operational scripts, workflow guidelines, and reference catalogs to perform complex architectural, security, and cost-engineering tasks.

## Skills Catalog

| Skill | Description | Primary Scripts & Entry Points | Output Artifacts |
| :--- | :--- | :--- | :--- |
| **[`architecture_diagram`](./architecture_diagram/SKILL.md)** | Creates professional, dark-themed technical architecture diagrams and companion standalone HTML/SVG assets. | `resources/template.html` | `docs/*-architecture.md`<br>`docs/*-architecture.html` |
| **[`codemender`](./codemender/SKILL.md)** | Orchestrates pre-build SAST vulnerability discovery, exploit verification/PoC triage, and automated patching. | `scripts/codemender_cli.py`<br>`cm find`, `cm verify`, `cm fix` | `docs/codemender-*.md`<br>`docs/codemender-security-audit-summary.md` |
| **[`gcp_cost_estimator`](./gcp_cost_estimator/SKILL.md)** | Performs rigorous Google Cloud running cost estimation using real-time rates queried strictly from the live Billing API (zero local caching). | `scripts/query_gcp_pricing.py`<br>`scripts/calculate_bom_cost.py` | `docs/gcp_cost_estimate_<project>.md` |

---

## Skill Operating Guidelines

1. **Artifact Destination:** All operational reports, security assessments, cost models, and standalone diagrams generated by these skills must be saved to the project's [`docs/`](../../docs/) directory.
2. **Strict Live Pricing (Zero Caching):** The `gcp_cost_estimator` skill queries rates strictly from the live Google Cloud Billing API or official live pricing pages. No hardcoded or cached prices are permitted.
3. **Interactive Parameter Elicitation:** Agents must ask the user for all necessary sizing parameters and workload variables without making assumptions.
4. **User Confirmation for Security Remediations:** The `codemender` skill requires explicit user approval before applying security patches or modifying code.
